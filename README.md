# 星即 · 私人记账

一款不需要登录、数据只存在本机的记账应用。基于 uni-app（Vue 2）编写，同一套代码可发布为 Android App 与微信小程序。

## 功能

- **记账**：数字键盘输入金额，支持支出 / 收入切换、分类与子分类、账户、日期、备注
- **明细**：按月查看，按日期分组，支持关键词搜索、多条件筛选、日历视图
- **统计**：月度收支趋势、分类占比图表
- **账户**：现金、微信、支付宝、银行卡等，自动维护余额
- **分类**：内置常用分类，可自定义图标、排序、隐藏
- **预算**：月度预算与超支提醒
- **快捷模板**：常用账单模板，一键带出金额与分类
- **数据与备份**：CSV 导出、整库备份 / 恢复、清空账单
- **自动记账**：开启后读取剪贴板里的付款信息，回到前台弹窗一键入账
- **隐私模式**：全站金额显示为 `****`

## 技术栈

| 项 | 说明 |
| --- | --- |
| 框架 | uni-app + Vue 2（HBuilderX 工程） |
| 端 | Android App（App-Plus）、微信小程序、H5 |
| 存储 | `uni.setStorageSync`，全本地，无后端 |
| 图表 | Canvas 2D（legacy API，三端通用） |
| 金额 | 以「分」为单位存整数，避免浮点误差 |

## 本地运行

1. 用 HBuilderX 打开 `uni` 目录（注意：不是仓库根目录）
2. 运行方式任选：
   - **H5 预览**：运行 → 运行到浏览器
   - **Android 真机**：运行 → 运行到手机或模拟器（使用标准基座即可）
   - **微信小程序**：运行 → 运行到小程序模拟器（需在 `manifest.json` 填写自己的小程序 AppID）
3. 云打包 APK：发行 → 原生 App - 云打包，需要登录 DCloud 账号并获取 AppID

## 数据存储说明

- 所有数据保存在应用本地存储，不上传服务器，卸载或清理缓存会丢失
- 账单按月分片存储：`app_bills_YYYY_MM`
- 主要 key：`app_accounts`、`app_categories`、`app_bills_index`、`app_budgets`、`app_settings`、`app_templates`、`app_meta`
- 建议定期在「我的 → 数据与备份」中导出备份
